# Quantum-NLS-Integrability-Dev

Lean formalizations for nonlinear Schrödinger research by Nataša Pavlović, Matthew Rosenzweig, and Gigliola Staffilani.

- [GGE/Construction](GGE/Construction/README.md): periodic NLS generalized Gibbs ensembles and their finite-gap construction.
- [GGE/Derivation](GGE/Derivation/README.md): fixed-period derivation and results on the Birkhoff coordinates and flow.

Each project has its own build instructions, statement scope, license, and third-party notices.
